# artwork-gallery
Вебсайт, предназначенный для демонстрации художественных работ (изображений). Состоит из публичной стороны с размещёнными на сайте изображениями и приватной стороны с инструментами для загрузки изображений, редактирования и управления контентом сайта

Website for showing some artworks. Includes public side with hosted images and author info and private side for admin with tools for uploading, editing and managing its contents
